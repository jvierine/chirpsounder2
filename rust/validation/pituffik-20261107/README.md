The gate start sets `offset_us`; a physical 10 ms PRI retains an additional
2995 km of range. Do not fold the geometric delay modulo the PRI or subtract
it from displayed propagation ranges. `transmit_delay_us=0` is an uncalibrated
nominal source epoch, not a measurement of source electronics. Existing station
receiver-clock profiles are preserved.

Native configurations use GIRO programs 16829/13415: 2 MHz start, 25 kHz coarse
steps, 100 Hz physical pulses, two 5 kHz-spaced fine frequencies, four coherent
repeats and 0.32 s coarse dwell. Decode complementary-code pairs at the first
fine carrier (`multiplex_block_pulses=2`); other fine carriers are not combined
as if they had the same code phase. The 2–20 MHz grid covers the long program;
when the transmitter stops at 8 MHz the remainder can contain no source echo.
Products are thresholded sparse HDF5, with the standard 0–20 dB GUI scale.

THJ76 and Millstone share a waveform and schedule. Added THJ76 receiver products
are provisional source associations; quantitative frequency limits must remain
withheld. A running worker or a geometric range gate does not establish source
identity. Further coordinated timing observations can refine the source epoch.
